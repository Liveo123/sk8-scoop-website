## Selection and release gates

1. Confirm original production binary for all user-supplied artwork and the generator's licence/input rights; **do not infer possession of a website-ready file solely from a chat thumbnail**.
2. Seek original images first. Do not contact Cheadle Civic Society / contributors or buy imagery without explicit authorisation.
3. Store each candidate's canonical source URI, licence/permission, credit, alt, caption, crop intent and status in the shared Image Rights Register. The register currently has no verified clearance for the five Premier Cafe archive photographs.
4. Avoid pseudo-documents, invented likenesses, fake wartime hardware claims and picture captions that imply the Marthe/Gibson narratives are causally linked.
5. Prepare prospective assets as properly named WebP/JPEG with dimensions that work at desktop and phone widths, not merely technically valid images. Don't recolour CC BY-SA images without verifying derivatives/ShareAlike obligations.
6. Implement only on staging/preview, audit all thumbnails and article imagery, review mobile crops and broken-link/error cases, then seek Paul's explicit production approval.
7. Until approved, existing labelled live imagery remains in place and **no production file or source mapping changes are authorised by this review**.
