# SK8 Scoop homepage V3 — 11 September 2026

This pass implements ten homepage improvements requested after the NUE launch. The first six are explicit web-design issues; the remaining four address performance, conversion trust, information architecture, accessibility and search semantics.

## 1. Web design — desktop header is overcrowded
**Issue:** the homepage header presents Home, What’s On, Guides, Where to start, Join, Submit, Contact, Advertise and a second Join CTA. At desktop width this behaves more like a site directory than a primary navigation.

**Fix:** on the homepage desktop header, keep the high-value primary destinations visible and move secondary utility routes to the existing lower-page/footer navigation. Reduce header height, logo size, link gaps and CTA spacing. Mobile menu retains the full route set.

## 2. Web design — hero hierarchy is too poster-like
**Issue:** the large headline, image and full-width gradient compete for attention instead of creating one obvious join/read decision.

**Fix:** reduce the hero height and maximum headline size, add a compact “Free Friday newsletter · SK8” eyebrow, tighten copy width, improve image/text balance, and turn the signup/proof elements into a more coherent visual cluster.

## 3. Web design — weekly story cards feel inconsistent
**Issue:** the three cards have uneven visual rhythm because illustration labels, artwork and varying text lengths do not resolve to a consistent card structure.

**Fix:** use equal-height flex cards, calmer shadows, consistent radii, padded no-crop artwork, smaller mode labels, slightly tighter typography and bottom-aligned continuation links.

## 4. Web design — Explore SK8 is too tall on mobile
**Issue:** eight category cards become a long scroll, particularly once the grid falls to one column.

**Fix:** make the tiles more compact, reduce media/copy height, retain two columns on normal phone widths, only fall to one column at 360px and below, and strengthen hover/focus feedback without changing the established local artwork.

## 5. Web design — Latest Issue and Guides shelf is visually unbalanced
**Issue:** the tilted issue cover and three-guide layout create a busy lower-page shelf, while one guide is only a “coming later” placeholder.

**Fix:** remove the cover rotation, use a clearer orange top accent for the current issue, rebalance shelf proportions, use two useful guide cards, and remove the dead-end placeholder from the homepage.

## 6. Web design — Take part / lower page is too visually heavy
**Issue:** four 210px action cards with large numbered circles add a large utility block after an already long homepage.

**Fix:** convert them to compact utility cards with smaller markers, reduced padding, lower button weight and responsive 2x2 / 1-column layouts. The footer is also tightened so it supports rather than competes with the page above.

## 7. Performance — too much below-the-fold work
**Issue:** homepage story artwork is dynamically recreated as eager-loading imagery and multiple lower sections render immediately.

**Fix:** dynamically generated story images now use lazy loading and async decoding. Explore, feature and take-part sections use `content-visibility:auto` where supported, with intrinsic-size fallbacks to reduce rendering work and layout movement.

## 8. Conversion trust — proof is generic
**Issue:** the hero proof line says only LOCAL / Friday / free, even though current verified public figures are stronger.

**Fix:** show the rounded verified proof already used elsewhere: 500+ local readers, 12 issues published, and free every Friday. Add “No spam. Unsubscribe any time.” for new visitors only; recognised subscribers do not see signup microcopy.

## 9. Information architecture — two homepage continuations are weak
**Issue:** “See more” beside the weekly stories points to the latest issue rather than broader local content, and the guides shelf contains a non-clickable “coming later” card.

**Fix:** route the weekly-stories continuation to Around SK8 with a specific “Explore more local stories” label; rename the shelf to “Useful guides” and remove the unavailable guide card.

## 10. Accessibility and search semantics — homepage needs a stronger baseline
**Issue:** the homepage lacks homepage-specific keyboard-focus styling, reduced-motion handling and explicit WebSite/Organisation structured data.

**Fix:** add strong `:focus-visible` treatment, respect `prefers-reduced-motion`, label the hero signup form, and inject Organisation, WebSite and Periodical JSON-LD using current SK8 configuration.

## Release constraints
- Homepage-only visual layer. Existing category/NUE styles are not rewritten.
- Free & Cheap Guide content is not redesigned or rewritten.
- DICM artwork remains no-crop.
- Public subscriber proof remains rounded at 500+.
- Current issue remains Issue 12.
